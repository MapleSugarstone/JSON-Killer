JSON Killer

5MB JSON reduction for Scratch games.

An .sb3 is a zip. Costumes and sounds take up the majority of space, but the project.json needs to track them which quickly adds up. This strips out the redundant or bulky tracking without changing behaviour (hopefully). So now you'll have more space if the project.json exceeds the 5MiB limit!! Please save backups though, this is highly experimental.

This all runs in your browser, nothing is uploaded!

Method

  • Drops "topLevel":false, "shadow":false, "next":null. Every scratch-vm reader is a truthy test or null safe.
  • Drops empty "inputs":{} and "fields":{}. The deserializer walks both with for..in.
  • Drops the trailing null id from field arrays, read behind if (fieldId).
  • Drops costume md5ext when it equals assetId + "." + dataFormat, which scratch-vm rebuilds. Sound md5ext stays since it has no fallback.
  • Rounds rotation centre floats to 3dp, trimming noise like 299.50337500000004.
  • Deletes orphaned blocks, reachable from no top level script. Residue from deletions.
  • Keeps "parent":null. getTopLevelScript loops on while (block.parent !== null).
